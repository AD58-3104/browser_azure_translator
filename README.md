# 原文⇄翻訳トグル

Webページを Azure Translator またはローカルの LLM（Ollama）で翻訳し、ショートカット一つで **原文と訳文を瞬時に切り替える** Microsoft Edge / Chrome 向け拡張機能です。

ブラウザ標準の翻訳は、原文を確認したいときに毎回メニューを開く必要があります。この拡張機能は原文と訳文の両方を保持しているので、「訳がおかしい」と思ったらキーを押して原文を確認し、もう一度押せば訳文に戻れます。

## 機能

- **Alt+T**（またはツールバーのボタン）で翻訳。以降は押すたびに原文⇄訳文を切り替え（再翻訳は発生しません）
- 訳文表示中に **Ctrl を押しながらマウスを乗せる** と、その部分の原文をツールチップ表示
- 訳が怪しい段落にマウスを乗せて **Alt+R** を押すと、その段落だけを高品質なローカルモデル（例: TranslateGemma 12B）で訳し直す
- 段落単位でリンクや太字などのタグ構造ごと翻訳するため、文脈が途切れにくい
- `<code>` などのコード部分、`translate="no"` / `notranslate` 指定の要素は翻訳しない
- 画面付近の要素だけを翻訳し、スクロールに合わせて追加で翻訳（無料枠の節約）
- Azure 使用時は今月の送信文字数をオプション画面に表示
- 翻訳エンジンを Azure Translator / Ollama（ローカル）から選択可能
- ツールバーのバッジで状態を表示（訳：翻訳表示中 / 原：原文表示中 / !：エラー）

## 動作環境

- Microsoft Edge（Chromium版）または Google Chrome
- 次のどちらか
  - Azure Translator のリソースとキー（無料枠 F0 で月 200 万文字まで無料）
  - [Ollama](https://ollama.com/) と翻訳用モデル（完全無料・オフライン）

## インストール

ストアには公開していないため、開発者モードで読み込みます。

1. このリポジトリをクローン、または ZIP でダウンロードして展開します。
2. `edge://extensions`（Chrome では `chrome://extensions`）を開きます。
3. 「開発者モード」をオンにします。
4. 「展開して読み込み」をクリックし、`manifest.json` があるフォルダを選択します。
5. ツールバーの拡張機能アイコン（パズルピース）から、この拡張機能をツールバーに表示しておくと便利です。

読み込んだフォルダは移動・削除しないでください。更新したときは拡張機能一覧の「再読み込み」を押すと反映されます。

## Azure Translator の準備

1. Azure のサブスクリプションを用意します。学生なら [Azure for Students](https://azure.microsoft.com/free/students/) がクレジットカード不要で使えます。
2. Azure ポータルで「**Translator**」を検索してリソースを作成します。
   - 価格レベル：**Free F0**
   - リージョン：まずは **Global** を推奨
   - 「Azure AI services」（複数サービス版）ではなく、単体の「Translator」を選んでください。
3. 作成したリソースの「キーとエンドポイント」で、キー（KEY 1）と場所（Location）を確認します。

> **リージョン制限のエラーが出る場合**
> `RequestDisallowedByAzure` が出たら、サブスクリプションにリージョン制限のポリシーがかかっています。ポータルの「ポリシー」→「割り当て」で許可リージョンを確認し、その中から選んで作成し直してください。

## Ollama（ローカル推論）の準備

1. [Ollama](https://ollama.com/download) をインストールします。
2. 翻訳用のモデルをダウンロードします。

   ```sh
   ollama pull translategemma:4b
   ```

3. 拡張機能からのアクセスを許可するため、環境変数 `OLLAMA_ORIGINS` を設定して Ollama を起動し直します。設定しないと 403 エラーになります。

   **Windows**（設定後、タスクトレイの Ollama を終了して起動し直す）
   ```bat
   setx OLLAMA_ORIGINS "chrome-extension://*"
   ```

   **macOS**（設定後、Ollama アプリを終了して起動し直す）
   ```sh
   launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"
   ```

   **Linux（systemd）**
   ```sh
   sudo systemctl edit ollama.service
   # [Service] の下に Environment="OLLAMA_ORIGINS=chrome-extension://*" を追加
   sudo systemctl restart ollama
   ```

4. オプション画面で「Ollama（ローカル）」を選び、モデル名を入力して「接続テスト」を押します。

### 高品質モデルでの段落再翻訳

普段は軽いモデル（4B など）や Azure でページ全体を翻訳し、訳が怪しい段落だけを大きいモデルで訳し直す使い方ができます。

```sh
ollama pull translategemma:12b
```

オプション画面の「再翻訳に使う高品質モデル」にモデル名を入れておき、訳文表示中に段落へマウスを乗せて **Alt+R** を押します。処理中は段落の上に「再翻訳中…」と表示され、終わると訳文が差し替わって枠が点滅します。通常の翻訳エンジンが Azure でも使えます。CPU や統合 GPU のみの環境では、12B モデルで 1 段落 20〜30 秒程度かかります。

### コンテキスト長について

Ollama の既定のコンテキスト長は GPU メモリ量に応じて変わります（24GB 未満は 4k、24〜48GB は 32k、48GB 以上は 256k）。この拡張機能は既定では値を指定せず、Ollama の設定に従います。リクエストごとに異なる値を指定すると、そのたびにモデルが読み込み直されて遅くなるためです。

統合 GPU（メインメモリを共有する GPU）の環境では、搭載メモリ量によって 24GB 以上の VRAM があると判定され、32k になることがあります。同じ拡張機能でも PC によって既定値が異なる点に注意してください。

既定が 4k の環境で非常に長い段落を訳すと、プロンプトが切り詰められて訳がおかしくなることがあります。その場合は、Ollama 側で既定値を上げる（Ollama アプリの設定のスライダー、または環境変数 `OLLAMA_CONTEXT_LENGTH=8192`）のがおすすめです。拡張機能のオプションの「コンテキスト長」で指定することもできますが、CLI など他のクライアントと値が食い違うと、切り替えのたびにモデルの読み込み直しが起きます。

実際に使われている値は、モデルの実行中に次のコマンドの `CONTEXT` 列で確認できます。

```sh
ollama ps
```

翻訳の開始が毎回数十秒遅れる場合は、コンテキスト長の食い違いによる読み込み直しが起きていないか確認してください。

### 動作について

ローカル推論では段落を 1 つずつ翻訳し、訳せたものから順に表示します。CPU のみの環境では 1 段落に数秒かかることがあります。小型モデルがリンクや太字のタグ構造を崩した場合は、その段落をテキストのみで訳し直します（その段落のリンクは訳文表示中は失われます）。

## 設定

ツールバーのボタンを右クリック →「拡張機能のオプション」で設定画面を開きます。

| 項目 | 内容 |
| --- | --- |
| 翻訳エンジン | Azure Translator / Ollama（ローカル） |
| キー（Azure） | Azure Translator の KEY 1 または KEY 2 |
| リージョン（Azure） | リソースの場所（例: `koreacentral`）。Global で作った場合は空欄 |
| Ollama の URL | 既定は `http://localhost:11434` |
| 通常の翻訳に使うモデル | Ollama エンジン使用時のモデル（例: `translategemma:4b`） |
| 再翻訳に使う高品質モデル | Alt+R での段落再翻訳用（例: `translategemma:12b`） |
| コンテキスト長 | 空欄なら Ollama の既定値に従う（推奨） |
| 翻訳先の言語 | 既定は日本語 |
| 原文ツールチップ | Ctrl + ホバーで原文を表示するかどうか |

「接続テスト」「再翻訳モデルをテスト」で設定が正しいか確認できます。ショートカット（Alt+T / Alt+R）は `edge://extensions/shortcuts` で変更できます。

## 制限事項

- ブラウザ標準の翻訳と同時に使うと干渉します。対象のサイトでは標準翻訳をオフにしてください。
- React などで作られたページで、訳文表示中にページ側が内容を書き換えた箇所は、切り替えの対象から外れます。表示が崩れた場合はリロードしてください。
- iframe 内の文章は翻訳しません。
- `edge://` などのブラウザ内部ページや拡張機能ストアでは動作しません。
- Azure の送信文字数はタグを含めた目安で、Azure 側の課金カウントと完全には一致しません。

## 翻訳が途中で止まったとき

一時的なエラー（タイムアウトやレート制限など）は自動で再試行し、ほかの段落の翻訳は続けます。3 回失敗した段落や、キー・モデル名の誤りなどで止まった場合は、原因を直してから Alt+T で原文に戻し、もう一度 Alt+T を押すと未翻訳の段落だけ再試行します。

## プライバシー

- Azure 使用時、翻訳対象のページのテキストは Azure Translator（`api.cognitive.microsofttranslator.com`）に送信されます。Ollama 使用時は手元の PC の外には送信されません。
- API キーはブラウザの拡張機能ストレージ（`chrome.storage.local`）にのみ保存され、コードやリポジトリには含まれません。

## ファイル構成

```
manifest.json   拡張機能の定義（Manifest V3）
background.js   ショートカット・ボタン・バッジ・設定の管理
offscreen.html  翻訳処理用の非表示ページ
offscreen.js    翻訳リクエストの受け口。Service Worker の寿命制限を避けるためここで実行
translator.js   翻訳エンジン（Azure / Ollama）の呼び出し本体（offscreen を使えない環境では background.js から直接実行）
content.js      ページの走査、原文⇄訳文の差し替え、ツールチップ
options.html    設定画面
options.js      設定画面の処理
```
